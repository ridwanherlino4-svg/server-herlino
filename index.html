Fase 1: Pengenalan Konsep VPS & Cloud

Jelaskan secara singkat pemahaman Anda mengenai perbedaan layanan berikut dengan mengisi kotak yang tersedia.

Shared Hosting

Layanan hosting di mana satu server fisik digunakan bersama-sama oleh banyak pengguna. Biaya lebih murah, namun sumber daya (RAM, CPU) terbatas dan saling berbagi.

Dedicated Server

Penyewaan satu server fisik secara penuh untuk satu pengguna/organisasi saja. Performa maksimal dan kontrol penuh, namun biaya operasional sangat tinggi.

Amazon Lightsail

Layanan VPS cloud dari AWS yang praktis dan mudah digunakan dengan paket harga bulanan tetap, cocok untuk pemula atau aplikasi skala kecil hingga menengah.

Amazon EC2

Layanan komputasi awan AWS yang fleksibel dan skalabel dengan kontrol infrastruktur mendalam, menggunakan skema pembayaran sesuai pemakaian (pay-as-you-go).
